We want to combine these three projects:

- LectureGraph (Lectures → Interactive Concept Graph + Adaptive Quiz)
      • Pitch: Upload a slide deck and get a clickable
      prerequisite knowledge graph, timestamped slide jumps, and a quiz targeting
      your weakest concepts.
      • Demo hook: Drop in a real university lecture PDF/video and navigate the
      generated graph live.
- Paper2Sim (Research Paper → Runnable Experiment)
      • Pitch: Drop in an arXiv/bioRxiv PDF or URL and an agent extracts the
      equations/protocol, generates clean Python simulation code or wet-lab protocol
      steps, and plots reproduction results.
      • Demo hook: Upload a physics/ML paper PDF/url and watch it auto-generate and run
      a live interactive simulation plot.
- CiteCheck / HypothesisGraph (Literature Contradiction & Gap Finder)
      • Pitch: Ingests 50+ papers on a user entered topic (e.g., battery electrolytes or
      protein folding), maps claims vs. evidence, and highlights contradictory
      results and untested experimental gaps.
      • Demo hook: Query a niche scientific question and show an interactive graph
      of "Paper A claims X, Paper B refutes X under condition Y."

- Also add an interactive digital avatar which answers/explains concepts or thorough interactive visuals wherever required.
